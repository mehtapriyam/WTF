# Practical 6 — WanderGo Travels Pvt. Ltd.

## Aim
To implement asynchronous JavaScript using timers, callbacks,
Fetch API/AJAX, and browser storage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON
- localStorage
- sessionStorage

## Features
- Responsive travel portal
- Promotional messages using setTimeout() and setInterval()
- Callback-based asynchronous task
- Travel packages loaded from a local JSON file
- Dynamic destination cards and filtering
- Loading indicators and error handling
- Dark mode preference saved using localStorage
- Preferred destination saved using localStorage
- Browser session information using sessionStorage

## Project Structure
- index.html — Page structure
- style.css — Responsive styling
- script.js — Asynchronous JavaScript and browser storage
- destinations.json — Travel package data
- README.md — Practical documentation

## How to Run
1. Open the Practical-6 folder in Visual Studio Code.
2. Run index.html using Live Server.
3. Explore packages, filters, promotions, and preferences.

## Note
This is a front-end demonstration. It does not implement
real bookings, payments, or backend data storage.
