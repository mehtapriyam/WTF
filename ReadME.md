# ITUS102 -- Web Technology Framework (WTF) Practicals

**Faculty:** Prof. Priyam Mehta\
**Institution:** CHARUSAT University\
**Purpose:** Academic practical work completed as part of the Web
Technology Framework laboratory.

## Project Overview

This repository documents the progression of practical work from
semantic HTML and responsive CSS to JavaScript fundamentals, DOM
interaction, form validation, and asynchronous JavaScript. Each
practical is maintained in its own folder so that files and
implementation changes remain organized.

## Technologies Used

-   HTML5
-   CSS3
-   JavaScript
-   Visual Studio Code
-   Google Chrome and browser developer tools
-   Git and GitHub (where used for version control)

## Practical Work

### Practical 1 --- GreenLeaf Organics Website

**Aim:** Create a semantic HTML5 webpage and manage the project using
Git and GitHub.

Key work: - Semantic page structure using elements such as `header`,
`nav`, `main`, `section`, `article`, and `footer` - Company logo,
navigation, about section, products/services, banner, news/offer
content, contact information, and footer - Metadata, page title, and
favicon - Git repository and GitHub version-control workflow

### Practical 2 --- Responsive Web Design with CSS3

**Aim:** Design responsive web pages using CSS3, Flexbox, Grid, media
queries, cascading, and inheritance.

Key concepts: - CSS selectors and styling rules - Layout using Flexbox
and CSS Grid - Responsive layouts with media queries - Cascading,
inheritance, spacing, and visual consistency

### Practical 3 --- JavaScript Fundamentals

**Aim:** Develop JavaScript programs demonstrating variables, operators,
conditional statements, loops, and functions.

Key concepts: - Variables and data types - Operators and expressions -
Conditional statements - Iteration using loops - Reusable functions

### Practical 4 --- DOM Manipulation and Event Handling

**Scenario:** Interactive product/store-style webpage.

Key work: - Selecting and modifying HTML elements through the DOM -
Handling user events - Updating page content dynamically - Interactive
controls and product/cart-related behaviour - Theme switching and other
dynamic UI interactions

### Practical 5 --- CityCare Hospital Patient Registration Form

**Aim:** Design and validate HTML forms using JavaScript, regular
expressions, and input-validation techniques.

Key work: - Patient registration fields, radio buttons, checkboxes,
dropdowns, date input, password fields, and file upload - HTML5
attributes such as `required`, `placeholder`, `maxlength`, `min`, and
`max` - JavaScript validation for name, email, mobile number, password
strength, and password confirmation - Regular expressions and custom
validation messages - Input trimming and checks for disallowed
characters - File selection and Remove File functionality - Consent
validation and successful-registration feedback - Logo, favicon, and
responsive visual styling - Excel test-case sheet for student testing

**Note:** This is a front-end demonstration. A success message does not
mean patient information is saved to a database. Production systems
require secure server-side validation and storage.

### Practical 6 — WanderGo Travels Pvt. Ltd. (Completed)

**Aim:** Implement asynchronous JavaScript using timers, callbacks,
Fetch API/AJAX, and browser storage.

**Implemented features:**
- Responsive travel portal using HTML5 and CSS3
- Promotional messages using `setTimeout()` and `setInterval()`
- Callback-based asynchronous task
- Fetch API to retrieve travel packages from `destinations.json`
- Dynamic destination cards and filtering
- Loading indicators and error handling
- Theme and destination preferences using `localStorage`
- Browser session information using `sessionStorage`
- Travel package refresh and destination selection

## Running the Projects

1.  Open the required practical folder in Visual Studio Code.
2.  Open `index.html` in a browser, or use the Live Server extension if
    installed.
3.  Follow the test cases relevant to that practical.
4.  Check browser developer tools for JavaScript errors when
    troubleshooting.
5.  Keep each practical in its own folder.
