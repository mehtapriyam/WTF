# GreenLeaf Organics Website

## Project Description

This project is a simple semantic HTML5 website developed as part of the Web Development Fundamentals laboratory.

The website represents a fictional company named **GreenLeaf Organics Pvt. Ltd.** and demonstrates the use of HTML5 semantic elements.

---

## Technologies Used

- HTML5
- Git
- GitHub

---

## Features

- Semantic HTML5 Structure
- Company Logo
- Navigation Menu
- About Section
- Products Section
- Services Section
- Featured Banner
- Latest News
- Special Offer
- Contact Information
- Contact Form
- Footer
- Metadata and Favicon
