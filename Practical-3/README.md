# Practical 3 — JavaScript Fundamentals

## Aim
To develop JavaScript programs using variables, operators,
conditional statements, loops, and functions.

## Technologies Used
- HTML5
- JavaScript (ES6)
- Visual Studio Code
- Google Chrome

## Concepts Covered
- Variables using var, let, and const
- Arithmetic, relational, and logical operators
- Conditional statements: if-else and switch
- Loops: for, while, and do-while
- Functions with parameters and return values
- User input and dynamic output
- Testing and debugging JavaScript programs
