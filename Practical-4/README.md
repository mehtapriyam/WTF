# Practical 4 — DOM Manipulation and Event Handling

## Aim
To develop interactive web pages using JavaScript DOM
manipulation and event handling techniques.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## Concepts Covered
- DOM element selection and manipulation
- Dynamic content and style changes
- Creating, appending, replacing, and removing elements
- Click, mouse, keyboard, and change events
- Interactive buttons and feedback messages
- Dynamic UI features and theme switching

## Project Structure
- index.html — Webpage structure
- style.css — Page styling
- script.js — DOM and event-handling logic
- images/ — Project images
